Drawio Viewer 交互修复原型

问题分析

Bug 1 左键点击打开放大图而非拖拽

根因：graphConfig.lightbox 未显式设置（undefined）， lightboxClickEnabled = 0 != undefined = true， 导致左键点击触发 showLightbox() → showLocalLightbox()。

同时 setPanning(false) 硬编码关闭了 panning， 即使 move: true 也无法拖拽平移。


Bug 2 放大图中工具栏纵向排列

根因：lightbox 元素被 document.body.appendChild() 添加到 body， 不在 .drawio-viewer-root 容器内， CSS 隔离规则 .drawio-viewer-root img { display: inline } 无法覆盖 lightbox。 Tailwind preflight 的 img { display: block } 导致工具栏按钮纵向排列。

修复方案验证

Bug 1 修复

1. 在 data-mxgraph 配置中设置 lightbox: false，禁用左键点击触发 lightbox

2. viewer 初始化后手动调用 graph.setPanning(true) 启用拖拽平移

3. 添加右键上下文菜单，提供"打开放大图"选项，调用 showLocalLightbox()


Bug 2 修复

在 globals.css 中添加全局 CSS 规则， 恢复 lightbox（chromelessToolbar）内 img 的 display: inline。

选择器不能限定在 .drawio-viewer-root 下，因为 lightbox 元素在 body 下。
