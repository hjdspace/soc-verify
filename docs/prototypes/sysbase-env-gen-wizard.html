选择 Subsystem 与例化名
选择要生成验证环境的 Subsys，系统将自动推导例化名。
Subsys 名称需与项目仓库名一致，保证所有环节的 subsys name 统一。例化名用于在 top 上例化 DUT 时的命名。
Subsystem 名称 * -n
已知 Subsys 列表，后续可从 Case Database 动态获取
例化名 (Instance Name) * -i
规则：apcpu_sys → u_sys_apcpu，ap_sys → u_sys_ap
脚本路径 (sysbase_gen.py) 可修改
默认路径，可修改为其他版本
选择 DUT 顶层 RTL 文件
从 $PROJ_RTL/<subsys>/design/rtl/top/ 目录下选择顶层 .v 文件
$PROJ_RTL 环境变量已检测到：/pri/project/rtl。若不正确请先在环境变量管理中修改。
DUT 顶层文件 (.v) * -rtl
扫描 $PROJ_RTL/apcpu_sys/design/rtl/top/ 下的 .v 文件：
apcpu_top_pwr_wrap.v module: apcpu_top_pwr_wrap $PROJ_RTL/apcpu_sys/design/rtl/top/
apcpu_top.v module: apcpu_top $PROJ_RTL/apcpu_sys/design/rtl/top/
apcpu_cluster_wrap.v module: apcpu_cluster_wrap $PROJ_RTL/apcpu_sys/design/rtl/top/
Module 名（自动提取）
已提取
从 RTL 文件中自动提取 module 声明名，用于后续 Module IO 生成
DUT Spec Excel
提供填写好的 dut_spec Excel 文件，用于生成 systba VIP / sysbase BFM 组件环境
dut_spec 包含 Architecture 和 MemoryMap 两个 sheet，描述 Subsys 的接口和内存映射信息。
DUT Spec 文件路径 * -x
支持 .xlsx / .xls 格式。点击「打开模板编辑」可在应用内直接编辑空白模板

RAL 寄存器目录
由 DE 提供的所有 reg 目录所在的总目录，支持多个目录空格分隔
每个 reg 独立目录下应包含 for_de / for_dv 子目录。自动推导将扫描 spec 和 rtl 两个根目录。
已推导 3 个目录
RAL 目录列表 * -ral
$PROJ_RTL/apcpu_sys/design/spec/autoreg ✓ for_de ✓ for_dv
$PROJ_RTL/apcpu_sys/design/rtl/slv_fw_apcpu ✓ for_de ✓ for_dv
$PROJ_RTL/common/rtl/TDC_sensor_ctrl/RegsBuilder ✓ for_de ✓ for_dv
自动推导扫描 $PROJ_RTL/<subsys>/design/spec/ 和 $PROJ_RTL/<subsys>/design/rtl/ 目录
CLK 时钟目录
由 DE 提供的 clk_max cfg、set clk_freq task 和 clk_max sva 三份文件所在目录
CLK 目录 * -clk
扫描包含 clk_max_cfg 关键字的文件所在目录
CLK2 目录（可选） 多 clk core subsys 使用 -clk2
仅存在多个 clk core 的 subsys 需要，格式: <de路径>,<clk文件名前缀>
