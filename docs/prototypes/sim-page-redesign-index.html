仿真页面布局原型

当前问题：子系统/用例在左侧 FileDrawer 的 Tab 里（330px 宽、树很深），仿真 Option 在底部全局浮窗。 用户需要在左抽屉选用例 → 回到仿真页 → 展开 OptionDock → 运行，跨了三个空间。 以下 4 种布局将「用例选择 + 仿真选项 + 运行列表」整合到仿真页面，供挑选。

方案 1
左树 + 右选项面板
左侧用例树常驻（可折叠），右侧上方仿真选项卡片，下方运行列表。经典 IDE 三栏布局。
三栏IDE 风格用例树常驻
方案 2
Master-Detail 上下分区
上半区：子系统→用例水平浏览条 + 选中用例的选项卡片；下半区：运行列表。宽度自适应。
上下分区水平用例条紧凑
方案 3
左用例 Dock + 底部 Option Dock
左侧 dock 用例树面板（可收起为图标列），底部保留 Option Dock 但嵌入仿真页内部。最接近当前布局。
渐进改造Dock 面板低风险
方案 4
向导式三步流
Step1 选子系统→用例，Step2 配置选项，Step3 运行+监控。步骤条引导，左侧始终显示运行状态。
向导步骤引导新手友好

PROTOTYPE — 抛掷型代码，仅用于回答布局问题。选定后移入正式代码。
