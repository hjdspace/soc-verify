仿真选项 UI 原型索引

5 种设计风格，底部均含命令预览 + 运行按钮。点击卡片查看原型详情。

🗂️
01 · Tabbed Compact
标签页紧凑布局。顶部标签栏切换分组，底部命令预览栏 + 运行按钮。信息密度高，适合窄面板。
标签页 紧凑 高密度
📋
02 · Accordion Drawer
手风琴折叠面板。每个分组可独立展开/折叠，带摘要预览。底部命令栏 + 运行按钮。灵活控制显示范围。
折叠 Catppuccin 摘要
✨
03 · Glassmorphism
毛玻璃浮动面板。半透明背景 + 背景模糊 + 发光效果。Pill 式分组导航。视觉高级感，适合现代化设计。
毛玻璃 发光 Pill导航
⚡
04 · Split Live Preview
分栏实时预览。左侧表单，右侧实时命令预览 + 统计数据。底部命令栏 + 运行按钮。信息双栏，所见即所得。
分栏 实时预览 统计
🔻
05 · Minimalist Card
极简卡片布局。每个分组一张卡片，行内字段排列。底部命令栏 + 运行按钮。简洁纯净，极致克制。
极简 卡片 行内

共同特性

  • ✅ 底部命令预览栏：实时显示生成的 runsim 命令
  • ✅ 运行按钮：一键执行仿真
  • ✅ 预设管理：保存/加载仿真选项预设
  • ✅ 5 个分组：基础参数 / 波形配置 / 仿真参数 / 执行模式 / 回归测试
  • ✅ 26 个仿真选项字段，支持 string / boolean / enum 类型
  • ✅ 命令语法高亮：flag（蓝色）/ value（紫色）/ base（绿色）
