## SoC Verify v0.3.0

本版本是 v0.3.0 里程碑发布，核心新增了**知识库全功能模块**和**SoC 验证环境生成器（sysbase-gen）**两大功能板块，同时引入 DrawIO 图表查看器、Cadence IMC 24.09 适配、主题持久化、交互式 AskQuestion 工具等多项增强。

## Highlights

- **知识库（KB）全功能迭代**：完成从 anydoc 依赖接入、Conversion 服务、KB 注册/挂载/kb-router 最小闭环，到上传-转换-分类-索引流水线、Host Tools 与索引上下文注入、知识库 UI（列表/索引/预览 Tab + 移动分类 + 深度重建）、kb_search 挂载检测与 markitdown 第二引擎、AI 分类降级/重分类及凭证模型字段的完整闭环
- **SoC 验证环境生成器（sysbase-gen）**：新增向导式 UI（DUT Spec / Mini Case / CLK / RAL / Module IO / Optional / Subsys / RTL / Review 九步），配套 Zustand store、命令构建器、目录推断、模板加载、路径扫描、Module IO runner、gen-runner 事件执行、配置持久化、tRPC 子路由与共享类型
- **DrawIO 图表查看器**：新增 DrawIO 图表支持及相关工具，支持中键拖拽缩放交互
- **Cadence IMC 24.09 适配**：适配 IMC 24.09 新命令格式，新增层级覆盖率解析
- **登录 Shell 环境捕获**：新增登录 shell 环境捕获逻辑，正确检测 EDA 工具与环境变量
- **应用单实例锁**：防止应用多开
- **主题持久化**：通过 tRPC settings + Zustand 实现主题持久化，防止默认主题闪烁
- **交互式 AskQuestion 工具**：新增 IPC 转发、answer 格式化、AskQuestionCard 组件的完整处理链路
- **关闭所有 Tab**：新增 CenterArea 关闭所有 Tab 功能与项目切换 switchProject 方法
- **终端选中文本复制**：终端视图支持选中文本复制
- **XLSX 增强**：新增列宽格式转换功能与 XlsxEditor onSaveAs 回调
- **ComposerEditor 组件**：新增 ComposerEditor 组件并集成到 RightPanel
- **Diff 审查增强**：reviewedFiles 持久化、warning 结果处理、加载失败错误处理
- **项目恢复**：启动时项目恢复与子系统动态获取过滤

## Fixes

- 修复 DrawIO lightbox 工具栏布局异常并添加拖拽交互
