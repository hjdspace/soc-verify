## SoC Verify v0.2.0

本版本重点交付完整的插件扩展宿主体系，补齐编辑器预览与字体管理能力，并完善仿真终端与 AI 错误分析的功能迭代，是向插件生态化演进的关键版本。

## Highlights

- **插件扩展宿主体系**：完成 VS Code 风格插件扩展宿主实现，支持命令和视图贡献；扩展宿主视图容器与宿主 API，增强插件与宿主的集成能力；完成插件生命周期 SDK 与迁移，提供完整插件开发与迁移支持
- **编辑器预览增强**：添加 HTML 文件预览和在外部浏览器中打开功能；支持 Markdown 预览中点击内部链接打开文件
- **字体管理**：实现字体管理功能，支持 UI 字体、代码字体和字号预设，提升个性化体验
- **底部终端面板**：添加可折叠的底部终端面板，支持拖拽调整大小和内容显示，优化终端工作流
- **仿真终端与 AI 错误分析**：完成仿真终端与 AI 错误分析功能迭代
- **工具元数据与 UI 展示**：新增工具元数据、会话回调与 UI 展示优化
- **Markdown HTML 渲染**：添加 rehype-raw 支持 HTML 渲染

**Full Changelog**: https://github.com/hjdspace/soc-verify/compare/v0.1.10...v0.2.0
