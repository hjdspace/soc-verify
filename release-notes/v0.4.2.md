## SoC Verify v0.4.2

本版本重点增强了仿真调试能力与回归启动流程，同时引入视觉库优化 UI 体验，新增 CSV 编辑器与结构化错误展示组件。

## Highlights

- **仿真调试**：新增 SimArtifactResolver 仿真产物解析器，正确解析仿真日志路径（$PROJ_WORK 优先），新增仿真调试工具集（sim-debug.ts）、内联调试按钮与浮动调试停靠栏原型
- **回归启动流程**：新增 RunConfigModal 回归配置弹窗、回归命令构建器与统一启动流程（PRD + ADR），RegressionView 增强运行配置与活跃回归展示
- **视觉增强**：集成 ThinkingOrbs 替换 AI 加载指示器，liquid-gooey NavRail 视图切换指示器，border-beam 集成到焦点/审批组件
- **CSV 编辑器**：添加 CSV 文件表格编辑器组件
- **结构化错误展示**：新增结构化错误消息展示组件
- **文件树懒加载**：FileTree 新增 dirId 属性支持按需展开，移除目录预取
- **AI 面板**：添加 AI 面板折叠按钮，创建 ai-panel.css 设计令牌样式与原型 UI
- **仿真增强**：仿真记录新增 command 和 cwd 字段，新增 rerun 按钮与 EDA 工具启动器
- **会话增强**：会话路由 holistic swap 功能，日志模块新增 LogEvent 与 registerLogSink，stdout 写入拦截确保 JSONL 合规
- **工具组件**：新增 CopyButton 组件，ReadBody 支持目录结果，ToolCard 增强目录处理，GrepBody 正则高亮

## Fixes

- 修复模拟目录失效时错误分析失败
- 修复仿真目录路径与状态检查
- 修复 tsconfig.json 引用格式

## Refactor

- 文件树替换 lucide 图标为本地 VS Code 图标集，移除目录预取改为展开时按需加载
- NavRail 移除液态指示器改用底线激活态
- 重构目录安全检查并新增 containment 方法
- 重构回归终端处理与 runsim 命令生成解析
- 重构多个工具组件（BashBody、EditBody、WriteBody、GrepBody→GlobBody、DiffLineView、MarkdownRenderer、McpBody 等）
- 移除 OptionCard 回归测试功能与 pickRegrFile procedure
