## SoC Verify v0.2.6

仪表盘全功能上线，验证管理平台核心数据可视化能力全面增强。

## Highlights

- **仪表盘完整实现**：新增 Overview/Trend/Failures/Regression/Duration/Unstable/Phase 七大数据标签页，涵盖回归趋势、失败分布、持续时长统计、不稳定用例识别、阶段与调试难度分析，全部基于 ECharts 可视化
- **终端适配优化**：新增自定义 bashrc 配置，提升 Linux 终端兼容性
- **Linux 构建改进**：支持通过环境变量自定义 Node.js 下载源，便于离线/内网环境

## Fixes

- 修复 env-checker 过滤器处理逻辑与相关 bug

## Refactor

- 重构可疑文件管理流程与持久化逻辑
- 重构 EnvChecker、EnvCheckerRouter、回归分析工具、覆盖率合并工具等多个模块的默认目录获取与导入流程
- 优化项目目录解析与 Git 仓库扫描流程
