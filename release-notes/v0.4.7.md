## SoC Verify v0.4.7

本版本的核心是全新 **RTL 设计视图** 的完整落地，同时对主题切换、Token 监控、会话加载等关键路径做了大规模性能优化。

## Highlights

- **RTL 设计视图（ADR 0032）**：设计源码层级树侧边栏、Protocol Bundle 引擎与可下钻框图渲染、框图连线自动绕行与锚定优化
- **RTL LSP 工具链**：slang-server LSP bridge（diagnostics + hover + definition）与 verible lint 接通编辑器
- **目录扫描式设计源**：支持扫描方式导入设计源，Windows 退化 git symlink 解析，默认排除 pre_dv/fpv 目录
- **RTL 工具分发**：`download:rtl-tools` 支持 Windows + Linux 平台，新增工具状态查询
- **仿真面板增强**：CaseCfgPanel 批量模式与节点控制，仿真视图 keep-alive，子系统（subsys）查询接入

## Fixes

- 修复 Windows 路径解析问题并优化 RTL 视图 UI 交互
- 修复 dock 模式下 NavRail AI 按钮行为
- 为 Electron GUI 进程注入默认 TERM，修复跨平台终端行为不一致

## Performance

- 主题切换重构为 View Transitions，requestAnimationFrame 批量重建
- Token 监控日志扫描改为流式解析（Claude/codex JSONL）+ 异步文件操作 + 批量写入
- 会话消息懒加载与切换性能优化、Markdown 渲染缓存、Drawer/Resize Pointer Events 重构
