## SoC Verify v0.2.4

本版本实现基于 SQLite 的用例数据库方案，将 case 数据源从插件切换到 cases DB，新增数据库查看功能，并改进子系统用例加载体验。

## Highlights

- **用例数据库**：实现基于 SQLite 的 Case Database + Scanner，getSubsystems 从 DB 读取；CaseStatsService 全量从 DB 读取，新增 Repository 查询方法，移除 PluginBackedDiscovery 依赖和 TTL 缓存
- **Case Phase 字段**：新增 case 信息的 phase 字段支持
- **数据库查看**：新增 SQLite 数据库查看功能
- **USVP 伪子系统**：新增 USVP 伪子系统支持，改进 case parser
- **SubsysList 优化**：文件节点默认折叠，按需点击展开，保留批量展开/折叠和搜索点击功能

## Fixes

- 修复 case-scanner 清除数据顺序以适配外键约束

## Refactor

- 实现 ADR 0017，将 case→subsys 数据源从插件切换到 cases DB
- 重构 SubsysList 子系统用例加载和展开逻辑
- 简化 case-scanner 同步模式清理逻辑
