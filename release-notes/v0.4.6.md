## SoC Verify v0.4.6

本版本上线全新 **Token 用量监控视图**（独立 SQLite 记录 + 外部日志扫描调度），并对终端做了整体大升级——Enhanced Terminal 模式、OSC 133 命令边界追踪、主题系统与 Nerd Fonts，同时支持仿真 log-mode 偏好切换。

## Highlights

- **Token 用量监控**：内嵌视图按 ADR 0031 落地——旁路拦截会话 `message_end` 写入 SQLite，定时扫描 claude-code/codex JSONL 日志；总览/趋势/模型/会话四个面板配合热力图与连续天数统计
- **Enhanced Terminal 模式**：终端新增 zsh + Starship 增强模式，OSC 133 序列标记命令边界并在面板渲染命令装饰
- **终端主题系统**：内置多套配色与自定义主题管理，可在设置页 AppearanceTab 选择并持久化
- **Nerd Fonts + WebGL**：应用启动自动注入 Nerd Fonts（含字体下载脚本），终端渲染切换 WebGL 加速

## Features

- 仿真结果支持 log-mode 偏好切换（设置面板开关 + 持久化 + toast 通知）
- 改写型动作在 AI 任务运行中转为填入输入框，并支持替换文件选区
- SCM 状态刷新与目录展开状态持久化增强

## Fixes

- 修复 PowerShell OSC 133 集成与终端面板显示问题
