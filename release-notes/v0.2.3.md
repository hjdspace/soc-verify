## SoC Verify v0.2.3

本版本重构 HostTools 架构为注册器 + 工具模块，新增 17 个工具子路由的完整后端实现，完善终端与仿真控制体验，并增强窗口管理与 Linux 平台支持。

## Highlights

- **HostTools 架构**：拆分 HostTools 单体为注册器 + 工具模块，新增 EventRelay 实现 IPC 事件转发与管理，新增 RTL 上下文、仿真、覆盖率统计、文档创建和 xlsx 编辑等 Host Tool
- **工具子路由**：新增 17 个工具子路由的完整后端实现，覆盖 time-analyzer、system-monitor、sv-ifdef-checker、regression-list-gen/analyzer、register-table-parser、reg2c、log-analyzer、git-quick-pull/manager/diff、find-replace、env-checker、coverage-merger、code-line-counter、c-sv-converter、batch-execution
- **Git 仓库管理**：实现 GitManager 完整能力，新增 RepoCard、TagDialog、UpdateDialog、SingleRepoUpdateDialog 组件，支持批量更新与回主分支
- **终端与仿真**：新增 TerminalPanel 组件和 SimControlToolbar 仿真控制工具栏，增强 runsim 命令解析，新增 rerunWithCommand 和 getSeedFromLog
- **窗口管理**：实现窗口工厂与 IPC 控制，新增系统托盘功能和窗口关闭偏好管理
- **Linux 平台**：新增 IME 和 D-Bus 设置，完善终端依赖兼容性
- **覆盖率**：在 worker 线程中解析覆盖率，新增插件路径解析，优化 CoverageTreeTable 和 CoverageDashboard 性能
- **会话管理**：实现 SessionContextFactory 会话上下文工厂

## Refactor

- 用 TerminalPanel 替换 TerminalView（CenterArea 和 BottomPanel）
- 重构 CoverageDashboard 和覆盖率管理器以提升性能
- 重构 GitManager 以增强仓库管理
- 重构 tv-ai-advisor 会话创建逻辑
- 简化 tools 路由结构，重构 RegressionListGen 为 TypeScript
- 重构 C/SV 转换器、寄存器表解析器和覆盖率合并器增强功能
- 清理冗余代码并完善 Linux 终端依赖兼容性
