## SoC Verify v0.2.2

本版本交付全新的 Surface 视图架构与浏览器能力，新增 18+ 验证工具集，并完善时序违例的 AI 建议与回归扫描闭环。

## Highlights

- **Surface 架构**：实现 View Manager 核心和 Document Surface 迁移，统一视图边界与叠加层同步
- **浏览器能力**：新增 Browser Surface，支持标签持久化、书签管理、SSO 登录、下载管理、页内查找和快捷键
- **工具集**：新增 18+ 验证工具，包括 Git 管理、寄存器表解析、寄存器转 C、SV 检查、批量执行、覆盖率合并、日志分析等
- **时序违例 AI**：新增 TV AI Advisor 提供智能建议，支持 Pattern 管理和回归扫描
- **时序违例管理**：新增导出/导入、分布图表、case corner 加载和 reset interval 配置
- **覆盖率与概览**：新增覆盖率导入进度跟踪和项目概览缓存

## Refactor

- 重构导航状态获取逻辑，统一使用 navigationHistory 对象
- 时序违例模块重命名 dbPath 为 dataDir，改进目录处理
- 批量清理未使用变量、导入项和冗余依赖
