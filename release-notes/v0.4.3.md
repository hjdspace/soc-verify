## SoC Verify v0.4.3

本版本重点优化了 AI 聊天流式体验与工具卡片渲染，新增用例配置管理面板与 Apple 双主题，并修复了推理模型 thinking 模式下的 tool_calls 兼容性问题。

## Highlights

- **聊天流式体验**：新增流式文本模糊尾缘与行内光标、回合收尾操作栏，回合后自动生成建议追问；流式尾缘仅应用于最后一个文本块，消除兄弟块级重复模糊
- **工具卡片**：集成 ToolChips 分组式渲染——折叠头 + 行式条目 + diff chips 悬停预览；ToolCard 实现技能读取检测与 skill 徽标
- **用例配置管理**：仿真视图左侧面板新增 tab 切换与 CaseCfgPanel 用例配置组件，新增 caseCfgRouter 与 Case Cfg Manager 支持自定义用例文件管理
- **AI 模型配置**：新增 thinking level 配置（模型配置、runner RPC、AI composer），每个 credential 可选择 OpenAI API 格式（chat/completions vs responses），TraceWeave 升级 v2.0 并内置 MCP 就绪诊断
- **SCM diff 审查**：源代码管理支持点击文件展开 diff 审查
- **Apple 主题**：新增 Apple Light / Apple Dark 双主题，主题选择替换为 ThemeGroup 组件
- **仿真增强**：仿真运行 command/cwd 持久化到数据库，ScreenshotsPreview 支持图片缩放与拖拽，目录搜索、命令预览与预设保存功能增强
- **路径支持**：项目路径支持 `~` 波浪号展开，agent 工具参数 home 简写不再报错

## Fixes

- 修复 deepseek 系 thinking 模式 tool_calls 400：推理模型声明 reasoning_content 回传 compat
- 修复流式尾缘应用于兄弟文本块导致的重复模糊
- 修复 regenerate 命令失效
- 修复仿真 store 活跃运行列表重复显示

## Refactor

- 枚举渲染统一为 EnumField 组件，OptionCard/OptionField 组件重构
- 背景类统一调整（bg-glass/bg-scrim），新增动画令牌与 reduced motion 支持
- 文件树图标处理简化，用例树渲染与动画优化
