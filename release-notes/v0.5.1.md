## SoC Verify v0.5.1

本版本完成知识库（KB）模块从零到一的全面重构，落地 LLM Wiki 双层架构，涵盖来源导入、分段编译、图像提取、混合检索、结构化审阅、质量门禁、安全撤回等 29 个 issue 闭环。

## Highlights

- **Wiki 双层架构**：知识库重构为 LLM Wiki 双层架构，落地注册/路径防护/原子提交原语，支持来源导入与修订保留（issue 01-02）
- **Wiki 浏览与审阅**：wiki 页面只读浏览、统一链接解析、知识提案 staging 与独立审阅入口、整页审阅后安全发布并保存历史（issue 04-06）
- **分段编译**：打通短来源编译与人工发布，流完整度有界修复与失败诊断，分段编译长手册并恢复断点，source-aware merge 与 compile cache 增量跳过（issue 08-10, 16-17）
- **PDF 图像提取**：提取 PDF 图像与矢量页并定位原文，配置视觉模型审阅图像解读，批量读图去重缓存与续跑（issue 11-13）
- **混合检索**：统一关键词检索与 Agent 知识导航，分页读取知识页及修订证据，hybrid search（RRF 融合）与索引重建（issue 14-15, 24）
- **向量索引**：embedding 能力逻辑层，分块向量索引（含 revision/coverage/status）（issue 21-22）
- **知识图谱**：统一知识图谱与图扩展搜索，图洞察（桥接节点与稀疏社区），sigma/worker 布局图视图（issue 23, 26）
- **结构化审阅**：结构化 lint 与 finding 持久化，语义 lint/lint 修复/sweep 审阅（issue 25, 27）
- **来源管理**：安全撤回来源与停用知识库，页面历史读取与回滚提案（issue 19-20）
- **查询保存**：saveQuery — 将聊天 Q&A 保存为可审阅的查询页面（issue 18）
- **质量门禁**：SoC 知识与检索证据质量门禁与合成样例库，退役旧 KB 入口点与未调用模块（issue 28-29）
