## SoC Verify v0.4.0

仿真视图全面重构为三栏布局，新增 agent 工具管理与全局错误处理机制，并为 Codex 引擎集成铺设 SDK 基础。

## Highlights

- **仿真视图三栏布局**：整合 CaseTreePanel + SimOptionPanel + RunListPanel，实现子系统用例树、仿真选项面板与运行列表的三栏联动（Issues #3-#6）
- **仿真运行记录持久化**：仿真运行记录跨重启恢复，列表持久化到本地存储
- **Agent 工具管理**：新增 AgentToolsTab 组件与设置面板，支持启用/禁用 agent 工具，新增工具目录元数据与静态工具目录
- **全局错误处理**：新增 ErrorBoundary 组件、全局错误事件处理与未捕获异常处理器，提升应用稳定性
- **回归数据库同步**：增强 RegressionRunner 支持数据库同步功能
- **用例扫描监视**：实现 CaseStatsRegistry 扫描监视功能，RTL 目录文件监视与防抖
- **会话改进**：会话中止处理改进、瞬态传输错误处理、AI 标题生成机制简化
- **Codex 引擎 SDK 桩**：新增 SessionManager、MCPManager、ModelRegistry、logger、mcp-client 等桩模块，为 Codex 引擎集成铺设基础
- **IPC 通道常量**：新增 ipc-channels.ts 统一管理 IPC 通道名称
- **子代理日志**：新增子代理生命周期与进度事件日志
