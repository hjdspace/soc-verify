## SpaceCode v0.3.2

本版本聚焦编辑器体验升级与核心流程稳定性增强。编辑器引入 Vim 模式、Minimap 缩略图、语法高亮、缩进指引等专业功能，Diff Review 重构为内联编辑器模式，同时修复了多项影响日常使用的稳定性问题。

## Highlights

- **编辑器大升级**：新增 Vim 模式、Minimap 缩略图、语法高亮、缩进指引、面包屑导航、状态栏及编辑器状态持久化，显著提升代码编辑体验
- **Diff Review 重构**：重构为内联编辑器模式，增强 diff 引擎稳定性，修复文件路径无法打开的问题
- **智能会话体验**：AI 自动总结会话标题，消息列表支持固定底部与滚动到底部按钮，Markdown 渲染子代理任务指令
- **TLS 证书自愈**：新增 TLS 证书自愈模块，解决本地代理导致的证书验证失败问题
- **Subagent 卡片 UI 原型**：新增 subagent 卡片 UI 方案原型及数据通路适配

## Fixes

- 修复 subagent 日志累积丢失问题，改为正序累积日志
- 修复 useSessionStore 订阅导致无限重渲染的问题
- 修复无语言标记的 fenced code block 被错误渲染为行内代码的问题
- 修复 Linux 上项目文件监视器递归导致阻塞的问题
- 修复 Linux 上 hover 样式丢失并添加按钮按下反馈

## Refactor

- 提取审批逻辑并支持对话历史种子恢复
- 提取 write snapshot 模块并支持自定义工作目录
- 合并覆盖率数据的批量加载，消除重复的 resolveSession 调用
- 将 PRD 和 Issues 文档按目录分类整理
